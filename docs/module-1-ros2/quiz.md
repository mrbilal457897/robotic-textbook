## Still Stuck?

### Common Misconceptions

**"ROS 2 nodes must run on the same computer"**
- **False**: Nodes can communicate across a network (with proper setup)

**"Topics are always best for robot communication"**
- **False**: Services are better for request/reply patterns; actions for long-running tasks

**"URDF describes physics"**
- **False**: URDF describes structure only; physics comes from simulators or SDF files

### Troubleshooting Tips

- **Review failed questions**: The explanations teach the concept, not just the answer
- **Run the code examples**: Hands-on practice is crucial for ROS 2
- **Ask questions**: Check the Resources section for community forums
