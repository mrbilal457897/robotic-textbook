# 模块 1: 机器人神经系统 (ROS 2)

**阅读时间:** ~5 分钟
**难度级别:** 初级至中级

## 概述

每个人形机器人—无论是在仓库中导航、协助医疗保健还是探索危险环境—都依赖于一个精密的神经系统来协调传感器、执行器和决策算法。ROS 2（机器人操作系统 2）充当这一神经系统，提供了支持分布式通信、模块化设计以及跨复杂机器人平台的实时控制的中间件基础设施。

与其前身 ROS 1 不同，ROS 2 建立在数据分发服务 (DDS) 标准之上，提供确定性通信、改进的安全性以及对多机器人系统的本机支持。这使其成为现代人形机器人的实际标准，其中子系统必须以毫秒精度进行协调——从调整关节扭矩的平衡算法到向操纵规划器馈送物体检测数据的视觉系统。

在本模块中，您将学习 ROS 2 如何支持模块化、可扩展的机器人架构。您将发现节点如何通过主题和服务进行通信，如何使用 Python 的 rclpy 库对机器人行为进行编程，以及如何使用统一机器人描述格式 (URDF) 对人形机器人结构进行建模。通过采用仿真优先的方法，您将在安全、可重复的环境中获得这些概念的实践经验，然后再触及物理硬件。

无论您是在构建感知管道、运动规划系统还是完整的人形应用，掌握 ROS 2 都是必不可少的。本模块提供了以信心设计、实施和调试分布式机器人系统所需的基础知识和实践技能。

## 学习目标

在本模块结束时，您将能够：

- **解释** ROS 2 架构，包括 DDS 中间件抽象、节点生命周期管理以及主题、服务和操作之间的区别
- **实现** ROS 2 节点，通过使用 Python 的 rclpy 库的发布-订阅（主题）和请求-响应（服务）模式进行通信
- **创建** 人形机器人的 URDF 模型，定义运动学链、关节类型、碰撞几何体和视觉表示
- **应用** ROS 2 最佳实践，如命名空间管理、参数配置和模块化系统设计的组成
- **分析** ROS 2 通信图使用内省工具 (ros2 topic, ros2 node, rqt_graph) 来调试数据流并识别瓶颈

## 模块内容

本模块分为三个渐进式主题，每个都建立在前一个主题的基础上：

1. **[节点、主题和服务](./01-nodes-topics-services.md)** — 理解 ROS 2 通信模型，包括用于流数据的发布-订阅模式和用于按需请求的客户端-服务器模式。了解节点如何交互、如何设计主题接口，以及何时使用服务相对于主题。

2. **[Python 和 rclpy](./02-python-rclpy.md)** — 使用 Python 的 rclpy 库编写强大的 ROS 2 应用程序。探索节点初始化、生命周期回调、参数处理、基于计时器的执行以及用于可靠通信的服务质量 (QoS) 策略。

3. **[人形机器人的 URDF](./03-urdf-humanoids.md)** — 使用 URDF 对人形机器人结构进行建模，定义链接、关节、质量属性和传感器放置。学习如何在 RViz 中可视化模型、将它们与 Gazebo 或 Isaac Sim 集成，以及为双足运动和操纵设计运动学链。

## 先决条件

在开始本模块之前，您应该具备：

- **Python 编程:** 熟练掌握 Python 3 语法、面向对象编程（类、继承）和基本并发概念（回调、异步模式）
- **Linux 命令行:** 熟悉终端导航、文件操作、包管理 (apt) 和环境变量
- **机器人基础知识:** 对坐标系、运动学、传感器（IMU、摄像头、LiDAR）和执行器（电机、舵机）的基本理解
- **开发环境:** ROS 2（Humble 或更高版本）安装在 Ubuntu 22.04 或等效版本上，或访问容器化 ROS 2 环境

如果您对这些主题中的任何一个都是陌生的，我们建议在继续之前查看介绍性资源。本模块假设您可以编写和执行 Python 脚本，并且可以在 Linux 终端中工作。

## 这对人形机器人的重要性

人形机器人带来了独特的挑战：它们在非结构化的人类环境中运行，需要用于平衡的紧密传感器-执行器回路，并且必须实时协调数十个自由度。ROS 2 的基于 DDS 的中间件提供：

- **实时性能:** 确定性通信用于时间关键的控制循环（例如以 100+ Hz 进行平衡稳定化）
- **模块化:** 用于感知、规划和控制的独立节点支持快速原型设计和并行开发
- **互操作性:** 标准化的消息类型和工具允许与第三方库（MoveIt、Nav2、Isaac SDK）的集成
- **可扩展性:** 分布式架构支持多机器人协调和基于云的计算卸载

通过在仿真（Gazebo、Isaac Sim）中掌握 ROS 2，您将开发能够直接转移到物理平台的技能—同时避免学习过程中的昂贵硬件故障。
